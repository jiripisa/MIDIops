# MIDIops v1 — Plan 5a: Settings mode + simple settings

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the global settings (MIDI-out channel, MIDI-in channel, clock-source flag) plus the existing scale/root to `AppServices`, filter incoming MIDI by channel in `AppShell`, and add a `SettingsMode` with two parameter screens to edit them.

**Architecture:** Settings live in `AppShell` and are exposed via `AppServices`; modes read them. `AppShell::onMidiIn` gains a global channel filter. `SettingsMode` reuses the Arp param-screen pattern (2×2 grid), which is extracted into a shared `core/render/ParamGrid.h` so both modes share it. The clock-source toggle is stored only (its behaviour is Plan 5b). No timing changes here.

**Tech Stack:** C++17, PlatformIO (envs `teensy41`, `native`, `test`), Unity, SDL2/RtMidi (sim), ILI9341_t3n (firmware).

Spec: `docs/specs/2026-06-09-settings-and-external-clock-design.md` (Plan 5a portion). Builds on Plan 4 (AppServices scale/root, ArpMode param screens).

### Task 2: MIDI-in channel filter in AppShell

- [ ] **Step 1: Add `isChannelVoice()` to `core/MidiMessage.h`** — inside `struct MidiMessage`, add:
```cpp
    // True for channel-voice messages (NoteOff..PitchBend = 0x80..0xE0).
    // Realtime/system messages (Clock/Start/Stop, added later) are not.
    bool isChannelVoice() const {
        const uint8_t t = static_cast<uint8_t>(type);
        return t >= 0x80 && t <= 0xE0;
    }
```

- [ ] **Step 2: Add the filter to `AppShell::onMidiIn`** in `core/app/AppShell.cpp`:
```cpp
void AppShell::onMidiIn(const MidiMessage& msg) {
    // Global MIDI-in channel filter: when not OMNI, drop channel-voice
    // messages on other channels. Non-channel-voice (realtime/system)
    // always passes.
    if (midiInChannel_ != 0 && msg.isChannelVoice() &&
        msg.channel != midiInChannel_) {
        return;
    }
    if (modeCount_ > 0) modes_[activeMode_]->onMidiIn(msg);
}
```

- [ ] **Step 1: Write `core/render/ParamGrid.h`** — move the existing helpers here verbatim, as `inline`/`namespace core` (so both ArpMode and SettingsMode share them):
```cpp
#pragma once

#include <cstdint>

#include "core/Display.h"

namespace core {

// 2x2 parameter-grid geometry (below the shell's 10px top bar).
constexpr int kParamGridTop = 12;
constexpr int kParamCellW   = 160;
constexpr int kParamCellH   = (240 - kParamGridTop) / 2;   // 114

// Cycle an enum value by `delta` steps (wraps around E::kCount).
template <typename E>
inline E cycleEnum(E current, int delta) {
    int n = static_cast<int>(E::kCount);
    int v = (static_cast<int>(current) + delta % n + n) % n;
    return static_cast<E>(v);
}

// Draws one grid cell: parameter name (small) above its value (large).
// col/row are 0..1 (col 0 = left, row 0 = top).
inline void drawParamCell(Display& d, int col, int row,
                          const char* name, const char* value) {
    const int x = col * kParamCellW;
    const int y = kParamGridTop + row * kParamCellH;
    constexpr int pad = 8;
    d.drawText(x + pad, y + pad,      name,  color::Gray,  color::Black, 1);
    d.drawText(x + pad, y + pad + 18, value, color::White, color::Black, 3);
}

inline void drawParamGridDividers(Display& d) {
    d.fillRect(kParamCellW, kParamGridTop, 1, 240 - kParamGridTop, color::DarkGray);
    d.fillRect(0, kParamGridTop + kParamCellH, 320, 1, color::DarkGray);
}

} // namespace core
```

### Task 5: SettingsMode + two screens

**Files:** Create `core/modes/SettingsMode.h`, `core/modes/SettingsMode.cpp`; Test `test/test_settings/test_settings.cpp` (new suite).

- [ ] **Step 1: Write `core/modes/SettingsMode.h`** — a `Mode` taking `AppServices&`, two screens ("midi", "scale"), `screenCount()==2`. Each screen edits via `AppServices` setters in `onEncoder` and renders with `drawParamCell`. Sketch:
```cpp
#pragma once

#include "core/app/AppServices.h"
#include "core/app/Mode.h"

namespace core {

class SettingsMode : public Mode {
public:
    explicit SettingsMode(AppServices& svc);
    const char* name() const override { return "Settings"; }
    int     screenCount() const override { return 2; }
    Screen& screen(int i) override { return i == 0 ? midiScreen_ : scaleScreen_; }

private:
    AppServices& svc_;

    class MidiScreen : public Screen {
    public:
        explicit MidiScreen(AppServices& s) : svc_(s) {}
        const char* name() const override { return "midi"; }
        void onEncoder(int index, int delta) override;
        void render(Display& d) const override;
    private:
        AppServices& svc_;
    };
    class ScaleScreen : public Screen {
    public:
        explicit ScaleScreen(AppServices& s) : svc_(s) {}
        const char* name() const override { return "scale"; }
        void onEncoder(int index, int delta) override;
        void render(Display& d) const override;
    private:
        AppServices& svc_;
    };
    MidiScreen  midiScreen_{svc_};
    ScaleScreen scaleScreen_{svc_};
};

} // namespace core
```

- [ ] **Step 2: Write `core/modes/SettingsMode.cpp`** — includes `core/modes/SettingsMode.h`, `core/Display.h`, `core/render/ParamGrid.h`, `core/Scale.h`, `<cstdio>`. Implement:

    - 1: `int v = svc_.midiOutChannel() + delta; clamp 1..16; svc_.setMidiOutChannel(v);`

    - 1: `svc_.setScaleType(cycleEnum(svc_.scale().type(), delta));`
    - 2: `int pc = ((int)svc_.scale().root() + delta % 12 + 12) % 12; svc_.setScaleRoot((uint8_t)pc);`

  - `SettingsMode::SettingsMode(AppServices& svc) : svc_(svc) {}`.
